# NeuroForge SDX — Ubiquitous Language Glossary

> Canonical vocabulary for all domain models, API contracts, code, tests, and documentation.
> Every engineer, agent, and generated artifact MUST use these terms exactly as defined.

| # | Term | Definition | Bounded Context | Example Usage |
|---|------|-----------|----------------|---------------|
| 1 | **WorkItem** | The canonical input document for a build pipeline. A structured manifest describing what to build, for whom, in which language, under which compliance profile. Immutable once approved. | WorkItem Ingestion | `workItem.status == PARSED` |
| 2 | **Build** | A single execution of the 16-stage pipeline for a WorkItem. Identified by a BuildID (ULID). Contains all stage results, gate outcomes, and artifact references. | Build Orchestration | `build.currentStage == 6` |
| 3 | **Pipeline Stage** | One of 16 sequential phases in a Build (Ingestion → Learning Loop). Each stage is a Temporal activity with retry, heartbeat, and compensation. | Build Orchestration | `stage.status == COMPLETED` |
| 4 | **Quality Gate** | A blocking check between pipeline stages. Evaluates a metric against a threshold. Failure activates a Remediation Loop, not a build termination. 14 gates defined (G-01..G-14). | Quality Verification | `gate.G01.value >= 0.80` |
| 5 | **Remediation Loop** | An automated corrective cycle triggered by a gate failure. The responsible agent is re-tasked to fix the issue. Max 3 attempts before human escalation. | Quality Verification | `remediationLoop.attempt == 2` |
| 6 | **Artifact** | Any immutable, content-addressed output of a Build: source code, binary, container image, Helm chart, SBOM, compliance package, or documentation. | Artifact Registry | `artifact.type == CONTAINER_IMAGE` |
| 7 | **Content Hash** | SHA-256 digest of an Artifact's contents. Used for deduplication, integrity verification, and content-addressing in RustFS. | Artifact Registry | `artifact.contentHash == "sha256:abc..."` |
| 8 | **Provenance** | SLSA Level 3 attestation documenting how an Artifact was produced: builder identity, build type, input materials, and build metadata. Signed with Cosign. | Artifact Registry | `provenance.slsaLevel == 3` |
| 9 | **SBOM** | Software Bill of Materials. A machine-readable inventory (SPDX or CycloneDX format) of all components, libraries, and versions in an Artifact. Generated by Syft. | Security Scanning | `sbom.format == SPDX` |
| 10 | **Agent** | A specialised AI worker with a defined role, LLM configuration, SPIFFE identity, and health status. Agents are the workforce of the factory. | Agent Orchestration | `agent.type == BUILDER` |
| 11 | **Agent Mesh** | The ensemble of all registered Agents, their health states, and communication topology. Agents communicate via NATS JetStream. | Agent Orchestration | `mesh.activeAgents == 15` |
| 12 | **Model Routing** | The process of selecting the optimal LLM for a given task class based on availability, cost, latency, and the agent's routing config. | Agent Orchestration | `routing.primary == CLAUDE_OPUS_4` |
| 13 | **Circuit Breaker** | A fault-tolerance pattern in the LLM Gateway. Trips after 3 consecutive failures to a model; enters half-open state after 30s cooldown. | LLM Gateway | `circuitBreaker.state == OPEN` |
| 14 | **Tenant** | An isolated organizational unit (company, team, or individual) with its own workspace, quotas, secrets, compliance profile, and billing meter. | Tenant Management | `tenant.plan == ENTERPRISE` |
| 15 | **Workspace** | A logical grouping of WorkItems and Builds within a Tenant. Members are authenticated via Authentik. | Tenant Management | `workspace.memberCount == 5` |
| 16 | **Plan Tier** | The commercial subscription level: STARTER, GROWTH, ENTERPRISE, or SOVEREIGN. Determines quotas, language access, and isolation level. | Tenant Management | `tenant.plan == SOVEREIGN` |
| 17 | **Quota** | A usage limit per Tenant per billing period: max pipelines/month, max languages, max storage GB, max concurrent agents. Enforced by sdx-gateway. | Tenant Management | `quota.pipelinesUsed == 28` |
| 18 | **Compliance Profile** | A Tenant-scoped configuration specifying which compliance frameworks (SOC2, HIPAA, GDPR, etc.) apply to their builds and what evidence is required. | Compliance Certification | `complianceProfile.frameworks == [SOC2, HIPAA]` |
| 19 | **Compliance Badge** | A per-build attestation indicating pass/fail status for each applicable compliance framework. Stored as part of the Build's CompliancePackage artifact. | Compliance Certification | `badge.soc2 == PASS` |
| 20 | **Evidence Package** | The immutable set of documents proving compliance control coverage for a specific Build: control matrix, test results, audit log excerpts, and SBOM. | Compliance Certification | `evidence.controlsCovered == 47` |
| 21 | **Domain Model** | The DDD representation of a WorkItem's business domain: bounded contexts, aggregates, entities, value objects, domain events, and ubiquitous language. | Domain Modelling | `domainModel.aggregateCount == 5` |
| 22 | **Blueprint** | The system architecture designed by ArchitectAgent: service topology, tech stack, API contracts, data models, and ADRs. Input for contract and code generation. | Architecture Design | `blueprint.serviceCount == 8` |
| 23 | **Contract** | An API specification (OpenAPI 3.1, AsyncAPI 3.0, or gRPC Protobuf) generated from a Blueprint. Used for test generation and implementation validation. | Contract Generation | `contract.type == OPENAPI` |
| 24 | **Test Spec** | A set of BDD scenarios (Gherkin) and failing test stubs generated from Contracts. Represents the RED phase of TDD. | Test Specification | `testSpec.scenarioCount == 23` |
| 25 | **Checkpoint** | A hash-verified snapshot of a Build's state, persisted to NATS JetStream every 30 seconds. Enables recovery from any failure without data loss. | Build Orchestration | `checkpoint.hash == "sha256:def..."` |
| 26 | **Human Escalation** | A PagerDuty alert raised after 5 consecutive automated recovery failures. Includes full diagnostic context: build state, gate results, agent logs. | Build Orchestration | `escalation.attempt == 5` |
| 27 | **CodeBLEU** | A reference-based metric for code generation quality, measuring n-gram overlap, syntax match, and semantic match vs. a human-written reference corpus. Gate G-01 threshold: ≥ 0.80. | Quality Verification | `codeBLEU.score == 0.84` |
| 28 | **Cyclomatic Complexity** | The number of independent paths through a function. Gate G-02 threshold: ≤ 10 per function. Exceeding triggers auto-decomposition. | Quality Verification | `complexity.value == 7` |
| 29 | **Zero Software Tax** | StratoGroup policy mandating all dependencies use Apache 2.0, MIT, MPL 2.0, or BSD licenses only. No GPL, AGPL, or commercial licenses. Gate G-09. | Quality Verification | `license.compliant == true` |
| 30 | **Holy Trinity** | StratoGroup's mandated development methodology: XP (iteration) + TDD (correctness) + DDD (domain accuracy). Every Build enforces all three pillars. | All Contexts | — |
| 31 | **AIDD** | AI-Driven Development. AI agents generate, review, and refactor code within a quality-gated pipeline supervised by humans. The 4th pillar augmenting the Holy Trinity. | All Contexts | — |
| 32 | **Idempotency Key** | A client-generated UUID attached to mutating API requests. Ensures that retried requests produce the same result without duplicate side effects. TTL: 24h in DragonflyDB. | API Gateway | `header: Idempotency-Key: uuid` |
| 33 | **Build Correlation ID** | A composite identifier (`build_id` ULID + `trace_id` W3C TraceContext) threaded through every event, log, and trace for full observability. | All Contexts | `correlation.buildId + correlation.traceId` |
| 34 | **NexoRegion** | A Tier 1 cloud region in UGCP NexoCloud: Lagos, London, Ashburn, Singapore, or Sao Paulo. Tenants are geo-fenced to their NexoRegion for data residency. | Deployment | `region == LAGOS` |
| 35 | **Audit Entry** | An immutable, hash-chained record in the audit log. Contains event type, actor, target, timestamp, and prev_hash. 7-year retention. | Audit | `auditEntry.prevHash == "sha256:..."` |
| 36 | **Durable Workflow** | A Temporal workflow whose state survives process crashes, network failures, and LLM API outages. The Build pipeline is a durable workflow. | Workflow Engine | `workflow.status == RUNNING` |
| 37 | **Language Router** | The subsystem within sdx-codegen-svc that selects the implementation language and per-language toolchain based on workload class, performance budget, and platform target. | Code Generation | `router.selectedLanguage == GO` |
| 38 | **Webhook** | An HTTP callback configured per Tenant for build lifecycle events (completed, failed, gate.failed, artifact.signed). Delivered at-least-once with HMAC-SHA256 signature. | API Gateway | `webhook.event == build.completed` |
