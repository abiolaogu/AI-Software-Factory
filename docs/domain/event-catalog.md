# Event Catalog

## workflow.created

Emitted when a new workflow is accepted and persisted.

## workflow.cancelled

Emitted when an in-flight workflow is cancelled by an operator or policy.

## prd.generated

Emitted when a PRD has been generated and stored.

## security.scan.started

Emitted when a security scan has been queued or launched.

## performance.test.started

Emitted when a performance run has been initiated.
